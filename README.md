# Анализ защищённости OWASP Juice Shop

Учебный отчёт по поиску, эксплуатации и устранению уязвимостей веб-приложения
[OWASP Juice Shop](https://github.com/juice-shop/juice-shop) — умышленно уязвимого
приложения от OWASP, предназначенного для обучения тестированию защищённости.

**Автор:** Шишкин Кирилл Владимирович, группа ИБ24-5
**Вуз:** Финансовый университет при Правительстве РФ, факультет информационных
технологий и анализа больших данных, направление 10.03.01 «Информационная безопасность»

> ⚠️ **Этично и легально.** Всё тестирование выполнялось исключительно на локальном
> учебном стенде (Juice Shop на Windows 10, атакующая машина — Kali Linux). Материал
> носит образовательный характер.

нумерация страниц). Для каждой уязвимости — как нашли, как эксплуатировать и как
исправить (с рекомендуемой моделью, кодом «было → стало» и схемой «как НЕ надо / как надо»).

## 🔎 Часть 1 — уязвимости (27)

1. **SQL-инъекция в форме входа (обход аутентификации)** — _A03:2021 – Injection_, критичность: Критическая.
2. **UNION-based SQL-инъекция в поиске товаров (выгрузка БД)** — _A03:2021 – Injection_, критичность: Критическая.
3. **NoSQL-инъекция (массовое изменение отзывов)** — _A03:2021 – Injection_, критичность: Высокая.
4. **DOM-based XSS в поле поиска** — _A03:2021 – Injection (XSS)_, критичность: Высокая.
5. **Отражённый XSS в параметре отслеживания заказа** — _A03:2021 – Injection (XSS)_, критичность: Высокая.
6. **Хранимый (persisted) XSS через HTTP-заголовок** — _A03:2021 – Injection (XSS)_, критичность: Высокая.
7. **Нарушение контроля доступа: доступ к разделу администрирования** — _A01:2021 – Broken Access Control_, критичность: Высокая.
8. **IDOR: доступ к чужой корзине** — _A01:2021 – Broken Access Control_, критичность: Высокая.
9. **Подделка отзыва от имени другого пользователя** — _A01:2021 – Broken Access Control_, критичность: Средняя.
10. **Mass Assignment: регистрация с правами администратора** — _A01:2021 – Broken Access Control_, критичность: Высокая.
11. **Сброс пароля через слабый секретный вопрос** — _A07:2021 – Identification and Authentication Failures_, критичность: Высокая.
12. **Отсутствие защиты от перебора (brute force) при входе** — _A07:2021 – Identification and Authentication Failures_, критичность: Средняя.
13. **Раскрытие данных: доступ к каталогу /ftp** — _A05:2021 – Security Misconfiguration_, критичность: Средняя.
14. **Обход фильтра расширений через Poison Null Byte (path traversal)** — _A05:2021 – Security Misconfiguration_, критичность: Высокая.
15. **Раскрытие конфиденциального документа о поглощениях** — _A01:2021 – Broken Access Control_, критичность: Средняя.
16. **Доступ к журналам сервера (/support/logs)** — _A09:2021 – Security Logging and Monitoring Failures_, критичность: Средняя.
17. **XXE: чтение файлов через загрузку XML** — _A05:2021 – Security Misconfiguration (XXE)_, критичность: Критическая.
18. **SSRF через подмену URL профильного изображения** — _A10:2021 – Server-Side Request Forgery_, критичность: Высокая.
19. **Подделка JWT через алгоритм none / слабый секрет** — _A02:2021 – Cryptographic Failures_, критичность: Критическая.
20. **Слабое хеширование паролей (MD5)** — _A02:2021 – Cryptographic Failures_, критичность: Высокая.
21. **Небезопасная десериализация / выполнение кода** — _A08:2021 – Software and Data Integrity Failures_, критичность: Критическая.
22. **Уязвимые и устаревшие компоненты (перезапись legal.md)** — _A06:2021 – Vulnerable and Outdated Components_, критичность: Высокая.
23. **Обход защиты от автоматизации (10+ отзывов за 10 секунд)** — _A04:2021 – Insecure Design_, критичность: Средняя.
24. **Отсутствие/слабость заголовков безопасности (CSP)** — _A05:2021 – Security Misconfiguration_, критичность: Средняя.
25. **Слабая криптография купонов (предсказуемые скидки)** — _A02:2021 – Cryptographic Failures_, критичность: Низкая.
26. **Безопасность через сокрытие (утечка до анонса)** — _A04:2021 – Insecure Design_, критичность: Низкая.
27. **Небезопасная загрузка файлов (тип и размер)** — _A04:2021 – Insecure Design_, критичность: Средняя.
